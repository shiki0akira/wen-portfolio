## Overview

This is Rong Xing Automation's warehouse management system. It handles receiving, shipping, inventory, storage locations and stock counts, and is used mainly by warehouse staff on the floor.

## The problem

- **Cluttered screens**: after a year of development and more and more features, staff struggled to find what they needed and made mistakes.
- **Desktop only**: staff walk around the warehouse, but had to go back to a computer to use the system.
- **No shared standards**: every screen looked different, so engineers kept checking back on details.

## What changed

- **Reorganised navigation**: grouped by task (master data, locations, stock counts, receiving, inventory, shipping), so common features are easy to find
- **Works on mobile**: tables become cards on small screens, so staff can work from a phone or tablet
- **A design system**: a component library built from scratch, so new features reuse it and updates go faster

## Results

- Redesigned a system that had been in development for a year, in just **2 months**
- Left behind a design system the team can keep using
