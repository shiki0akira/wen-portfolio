## Overview

Dive is BigGo's open-source AI desktop app. It connects to a range of large language models and uses MCP to let AI work with external tools, such as searching the web, reading files and generating images.

## How it works

1. Download Dive and choose an AI model
2. Add the MCP tools you want, for example from OAPhub
3. Give instructions as if chatting, and the AI calls the tools to get the job done
