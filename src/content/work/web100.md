## 背景

聚會、課堂破冰時，主持人常常要上網找規則、背台詞、準備道具。Web100 是一系列「打開網頁就能玩」的遊戲：不用下載、不用註冊，大家拿出手機就能開始。

## 我的角色

從想法、規則、設計到上線經營，都是我一個人完成。開發的部分，我先把規則寫成規格，再交給 Claude Code 實作，最後由我測試。

## 關鍵決策

### 一、做很多個小產品，而不是一個大平台

每個遊戲都是獨立的小產品，可以單獨上線、單獨被搜尋到，也能很快看出哪個真的有人玩。第一個產品只花了 4 個晚上。

### 二、一開始就支援 8 種語言

破冰遊戲不分國家都需要。AI 讓翻譯的成本變得很低，所以我一開始就做了 8 種語言。

<div class="todo">待補：8 種語言帶來的流量占比，或哪個語言意外地多。</div>

### 三、「玩得開心」不等於「會主動使用」

我親自帶朋友試玩，大家都玩得很開心，但之後很少有人自己打開來用。這讓我學到：要驗證的是真實的使用情況，不是第一印象。

<div class="todo">待補：試玩後具體調整了什麼？可以放一張帶大家玩的現場照（不露臉）。</div>

## 6 個產品

| 產品 | 怎麼玩 |
|---|---|
| 阿瓦隆語音主持 | 自動唸出主持人台詞 |
| 搶答遊戲 | 掃 QR code 加入，現場搶答 |
| 喜好二選一 | 答完自動分組，列出共同話題 |
| 幸福賓果 | 找人不找號碼的破冰賓果 |
| 定時炸彈 | 一台手機傳著玩，爆在誰手上誰輸 |
| 幸福模擬器 | 大螢幕加每人一支手機（[看案例](/work/happiness/)） |
